# HireMind

**HireMind** — это платформа для фрилансеров и заказчиков, которая убирает размытость требований к проекту ещё до начала работы.

Вместо старта с расплывчатых формулировок вроде «сделайте современно» или «нужно удобное приложение», HireMind помогает обеим сторонам заранее прояснить scope, ожидания, результаты, ограничения и критерии успеха.

### Статус
Концепт / продуктовая идея на ранней стадии.

## Что решает HireMind

Большая часть проблем во фрилансе начинается ещё до выполнения первой задачи:

- размытое или неполное ТЗ
- скрытые ожидания со стороны заказчика
- отсутствие бизнес-контекста
- неясные deliverables
- отсутствие понятного определения “готово”
- недооценка сроков и объёма работ
- конфликт между ожиданиями и бюджетом

Большинство фриланс-платформ оптимизируют поиск исполнителя.  
HireMind оптимизирует **понимание задачи**.

## Основная идея

До старта проекта HireMind проводит заказчика и фрилансера через структурированный процесс уточнения требований.

Платформа использует AI, чтобы:

- анализировать сырой запрос заказчика
- находить размытость, противоречия и недостающие детали
- генерировать уточняющие вопросы
- превращать требования в чистый и структурированный бриф / ТЗ
- определять deliverables, границы scope и критерии приёмки
- подсвечивать риски ещё до старта работы

Только после того, как обе стороны подтверждают уточнённый бриф, проект переходит в стадию выполнения.  
HireMind снижает хаос в проектах на самой ранней и самой критичной стадии: на этапе определения задачи.

Это приводит к:

- меньшему количеству недопониманий
- меньшему числу циклов правок
- меньшему числу споров по бюджету и срокам
- более точной оценке проекта
- более удачному мэтчингу между фрилансером и заказчиком
- большему доверию с обеих сторон

## Целевая аудитория

### Заказчики
Люди, которые понимают, какой результат хотят получить, но не умеют сформулировать технические или структурированные требования.

Примеры:
- основатели стартапов
- владельцы малого бизнеса
- соло-предприниматели
- нетехнические заказчики

### Фрилансеры
Специалисты, которым нужны более ясные вводные перед тем, как соглашаться на сроки, бюджет и scope.

Примеры:
- дизайнеры
- frontend/backend разработчики
- копирайтеры
- маркетологи
- product-специалисты
- no-code разработчики

## Пользовательский сценарий

### 1. AI-интерпретатор брифа
Заказчик описывает идею в свободной форме.  
HireMind превращает её в структурированный черновик брифа.

Пример входа:
> «Мне нужен сайт для кофейни, стильный, с бронью столиков и меню.»

Пример выхода:
- цель проекта
- целевая аудитория
- страницы / экраны
- необходимые функции
- зависимости по контенту
- дизайн-предпочтения
- предположения по срокам
- открытые вопросы

### 2. Модуль уточнения
Система задаёт уточняющие вопросы, чтобы убрать неоднозначность.

Примеры:
- Кто основной пользователь?
- Нужны ли онлайн-платежи?
- Бронирование должно быть по столикам или по временным слотам?
- У вас уже есть фирменный стиль?
- Что именно означает “современный дизайн” в вашем случае?
- Что входит в MVP, а что находится вне scope?

### 3. Конструктор scope
Преобразует обсуждение в чёткие границы проекта:
- что входит в scope
- что не входит
- какие функции можно оставить на будущее
- технические ограничения
- внешние зависимости

### 4. Definition of Done
Создаёт явные критерии приёмки:
- что именно должно быть передано в результате
- как проверяется завершённость работы
- что считается правкой, а что новым требованием

### 5. Выявление рисков
Подсвечивает типичные риски проекта заранее:
- нереалистичные сроки
- недостаточно описанные функции
- отсутствие контента / ассетов
- противоречивые требования
- несоответствие бюджета и объёма работ

### 6. Общий проектный бриф
И заказчик, и фрилансер работают с одной и той же версионируемой спецификацией:
- требования
- этапы
- предположения
- deliverables
- критерии приёмки
- заметки и принятые решения

### 7. Оценка готовности к старту
HireMind может рассчитывать уровень готовности / согласованности проекта на основе:
- количества отвеченных вопросов
- числа неустранённых неоднозначностей
- уровня риска
- полноты scope

Это помогает понять, действительно ли проект готов к старту.

### Пример конкретного пользовательского сценария работы

1. Заказчик создаёт идею проекта
2. AI анализирует сырой запрос
3. Платформа генерирует недостающие вопросы
4. Заказчик отвечает на уточнения
5. Формируется структурированный бриф
6. Фрилансер просматривает и комментирует его
7. Обе стороны подтверждают scope и ожидания
8. Проект переходит в активную работу

## Чем HireMind отличается

В отличие от классических фриланс-бирж, HireMind строится не только вокруг:
- профилей
- откликов
- отзывов
- переписки

Он строится вокруг **ясности брифа и согласованности scope**.

Ключевое отличие продукта — переход от:
> размытая идея -> структурированная договорённость

ещё до того, как деньги, дедлайны и давление по результату начинают создавать трение.

## Scope для MVP

MVP-версия HireMind может включать:

- создание проекта заказчиком
- AI-генерацию брифа из сырого запроса
- уточняющие вопросы
- редактируемый структурированный бриф
- режим ревью со стороны фрилансера
- общий флоу подтверждения
- статус готовности проекта
- простой чат / комментарии по требованиям
---

## Что не входит в MVP

Чтобы не размывать первую версию, в MVP **не обязательно** включать:

- полноценную биржу с откликами и конкурсами
- сложную платёжную систему
- escrow / безопасную сделку
- внутреннюю CRM
- продвинутую аналитику
- marketplace-алгоритмы ранжирования исполнителей
- сложную систему ролей и организаций

---
## Архитектурная идея

Проект задуман как web-платформа с AI-слоем, совместной работой в реальном времени и единым хранилищем версионируемых брифов.

### Основные модули системы

- **Auth** — регистрация, логин, JWT-аутентификация
- **Projects** — создание и управление проектами
- **Briefs** — структурированные брифы и их версии
- **Clarification Engine** — блок уточняющих вопросов
- **AI Layer** — анализ исходного запроса и генерация структуры
- **Review / Comments** — обсуждение требований между сторонами
- **Readiness Scoring** — оценка готовности проекта к старту
- **Files** — вложения, ассеты, материалы проекта
- **Search** — поиск по проектам, брифам, комментариям

## Локальный запуск
Требования:
- .NET 10 SDK
- Node.js
- Docker
- Docker Compose
- PostgreSQL
- доступ к OpenAI API
- S3-совместимое хранилище или локальный mock/minio
```bash
git clone <repo_url>
cd HireMind
cp .env.example .env
docker compose up --build
```
